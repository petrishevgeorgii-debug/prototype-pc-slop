The first public release of the native PC port of **PROTOTYPE** (PS4 *PROTOTYPE BIOHAZARD BUNDLE*, CUSA06545).

**No game files are included.** You need your own legally obtained, decrypted dump of CUSA06545 (01.00). Your game folder is never modified.

### Download and play
1. Download **PROTOTYPE-PC-Port-v0.4.0.zip** below and unpack it anywhere.
2. Start **Prototype.exe**, choose your game folder (with `eboot.bin`, `sce_sys`, `sce_module`, `p1`, `p2`), press **PLAY**. The first start prepares the game (about a minute).
3. In game, **Insert** or **R3 + L2** opens the port menu.

Needs Windows 10/11 64-bit and a Vulkan 1.3 GPU with a current driver.

### What's in it
- The PS4 game's own code running natively on the PC, with the shadPS4 video core on Vulkan
- Fixes: correct game speed, working saves, consume tendrils, steady frame pacing
- 60 FPS gameplay (videos and menus keep their speed)
- Render resolution from 720p to 4K (above 1080p experimental)
- **FSR 3.1 and FSR 4** (Radeon RX 9000) anti-aliasing and upscaling: Native AA, Quality, Balanced, Performance, Ultra Performance — switchable in game
- FSR 1, RCAS sharpening, 16× anisotropic filtering
- An in-game menu styled like the game's own options screens (English / Russian)
- A launcher with game folder checks, settings, save backups and the log

### Known issues
- PROTOTYPE 2 (bundle menu) does not start yet
- Tested on AMD Radeon only — **NVIDIA and Intel are untested**, please report how they run
- FSR 4.1 is hidden: AMD's Windows driver lacks a Vulkan feature it needs
- Slight ghosting on moving characters with FSR

### Reporting problems
Open an issue with your GPU, driver and `last_run.log` from the port folder.
